# Inbox

Default landing zone for raw brain dumps, screenshots, links, unclear tasks, and unprocessed files.

Operating rule: nothing lives here permanently. Each item should become one of:

- a next action in `03-ops-inbox-calendar-files/`
- a flywheel/system note in `01-ai-flywheel/`
- a content asset or workflow note in `02-content-engine/`
- a source/research note in `04-research/`
- an archived/reference item in `90-archive/`
