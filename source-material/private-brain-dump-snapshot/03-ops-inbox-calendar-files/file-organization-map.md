# File Organization Map

Purpose: keep the operating system clean without losing context.

## Folder Roles

| Folder | Role |
| --- | --- |
| `00-inbox/` | raw unprocessed notes, links, screenshots, dumps |
| `01-ai-flywheel/` | hardware, cluster, local inference, automation infrastructure |
| `02-content-engine/` | video, Kyanite Vocal Tarot, publishing workflow |
| `03-ops-inbox-calendar-files/` | personal ops, inbox, calendar, file management |
| `04-research/` | source-backed research notes |
| `90-archive/` | superseded or inactive reference |

## Intake Rule

Every new thing gets one of these labels:

- action
- waiting
- project
- reference
- archive
- delete

## Weekly Cleanup Rule

For each folder:

1. Move raw items out of `00-inbox`.
2. Promote active items into project folders.
3. Archive stale snapshots.
4. Delete obvious junk only when safe.
5. Leave credentials, settings, and account data alone.

## MacBook Pro Cleanup Translation

On the MacBook Pro, preserve:

- settings
- browser profiles
- passwords/keychains
- SSH keys
- Tailscale state
- project repos until inventoried

Clean:

- visible clutter
- downloads/installers
- duplicate media
- old app bundles
- generated build artifacts
